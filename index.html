Everything You Need, Nothing You Don't

Built for sysadmins who live in the terminal. Every feature designed to save you time.

🗂

Tabbed Sessions

Multiple connections in one window. Pin, reorder, duplicate tabs. Quick-switch with Ctrl+Tab.

📂

Built-in SFTP Panel

Drag-and-drop file transfers alongside your terminal. Browse, upload, download without leaving the session.

⌨️

Keyboard Macros

Record and replay keystroke sequences. 10 named macro slots with loop and repeat support.

📡

Session Broadcasting

Type once, send to all connected sessions. Perfect for multi-server configuration and deployments.

🔑

Credential Store

Encrypted local vault for passwords and keys. Auto-fill on connect, master password protection.

🎨

Themes & Palettes

Full 256-color palette editor. Custom themes, font management, transparency control, and dark mode presets.

🔁

Auto-Reconnect

Automatic reconnection on disconnect with configurable retry intervals. Never lose your session again.

📜

Command Snippets

Save frequently used commands with categories. One-click send with optional Enter key. Export and share.

🔌

Port Tunneling

Local, remote, and dynamic SOCKS5 tunnels. Multi-hop proxy chains. Visual tunnel manager.

📊

Session Statistics

Real-time bandwidth monitoring, command counters, uptime tracking, latency measurement per session.

🧩

Plugin System

Extend PuttyAlt with native C plugins. Hook into connect, disconnect, and data events. Hot-reload support.

📦

Portable Mode

Run from USB with all settings stored locally. Zero installation, zero registry entries. Take it everywhere.
