Feature-Rich

Everything You Need, Built In

50+ enhancements that turn a basic SSH client into a full-featured terminal workstation.

☷

Tabbed Sessions

Up to 64 concurrent sessions in tabs. Pin, reorder, rename. Ctrl+T to open, Ctrl+W to close — just like your browser.

▦

Split-Pane Terminal

Split horizontally or vertically into up to 4 panes. Monitor multiple servers side-by-side in a single window.

🔒

Encrypted Credential Store

AES-256-GCM encrypted password vault with master password. Never type credentials again. Zero plaintext on disk.

🔌

SSH Tunnel Manager

Local, remote, and dynamic SOCKS5 port forwarding. Visual tunnel dashboard with traffic stats.

⚙

Plugin System

Extend PuttyAlt with shared libraries. Hook into connect, disconnect, and data events. Full lifecycle API.

🎨

Themes & Palette Editor

5 built-in themes: Solarized, Dracula, Nord, Monokai, Gruvbox. Full 256-color palette editor with import/export.

📄

SFTP & SCP Panel

Split-pane file browser with sorting. Drag-and-drop uploads. SCP integration with progress tracking.

⚡

ZMODEM Auto-Detect

Automatically detects sz/rz initiation in terminal stream. Zero-config file transfers over existing sessions.

🕒

Keyboard Macros

Record and replay keystroke sequences with timing. 16 named slots, infinite loop playback. Automate repetitive tasks.

📑

Workspaces

Group sessions into named workspaces. Save & restore entire multi-server setups with one click.

📡

Serial Port

Full serial backend with baud rate, parity, flow control. Connect to network switches, Arduinos, embedded devices.

🔒

Portable Mode

INI-based config, zero registry. Run from USB drive. All settings in one file next to the executable.
