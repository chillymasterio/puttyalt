PuttyAlt v2.0.2 — Portable Edition
====================================

WINDOWS:
  Double-click windows/puttyalt.exe
  Or: windows\puttyalt.exe [user@]host[:port]

LINUX:
  chmod +x linux/puttyalt
  ./linux/puttyalt
  Or: ./linux/puttyalt [user@]host[:port]

CONFIG:
  Copy shared/puttyalt.conf.default to puttyalt.conf
  and edit to customize settings.

Both platforms read sessions from the same config format.
Carry this folder on USB — works everywhere.
