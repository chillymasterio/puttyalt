SSH, modernized.

PuttyAlt is a free, open-source SSH client built on the legendary PuTTY engine. Tabs. SFTP. Session manager. Scripting. Everything sysadmins have been asking for — finally in one tool.

What PuTTY should have been

All the features sysadmins have requested for 20 years — free and open source.

☷

Tabbed Sessions

Multiple connections in one window. No more juggling dozens of PuTTY windows on your taskbar.

📂

Session Manager

Organize hundreds of servers with folders, tags, and instant search. Color-code prod, dev, and staging.

📄

Built-in SFTP

Transfer files side-by-side with your terminal. No need for a separate WinSCP window.

🔒

Secure Credentials

Save passwords encrypted with a master key. AES-256 protection for your server credentials.

⌨

Scripting Engine

Automate repetitive tasks with Lua scripts. Record macros and replay them across sessions.

🔌

Portable Mode

Sessions stored in files, not the Windows registry. Run from a USB drive. Back up with a simple copy.

↺

Auto-Reconnect

Lost connection? PuttyAlt reconnects automatically. No more manual reconnect after network blips.

▶

Command Snippets

Save frequently used commands and send them with one click. Share snippet libraries with your team.
