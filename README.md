# PuttyAlt

> PuTTY 0.83 fork with modern UX: tabs, SFTP panel, session manager, and more.

Free, open-source, portable. MIT license.

## Building

```bash
git clone https://github.com/chillymasterio/puttyalt.git
cd puttyalt
cmake -B build
cmake --build build --config Release
```

## Based On

PuTTY 0.83 (2025-02-08) by Simon Tatham — includes ML-KEM post-quantum key exchange.
